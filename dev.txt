Conf File (Signet)
====================

# This config should be placed in following path:
# ~/.bitcoin/bitcoin.conf

    rpcuser=user
    rpcpassword=password
    server=1
    listen=1
    txindex=1
    zmqpubsequence=tcp://127.0.0.1:29000
    rest=1
    fallbackfee=0.00021
    chain=signet

    [signet]
    addnode=172.105.148.135:38333
    signetblocktime=600
    signetchallenge=00148835832e28c816b7acd8fdb19772ab2199603a56

    [main]
    addnode=157.180.8.224:8333
    drivechain=1   # only Core (patched) will notice this

( For forknet, just delete "chain=signet". )
